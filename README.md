## 🇬🇧 English

### About me

Hi! I'm **sklart**, an open-source enthusiast focused on maintaining, modernizing, and improving software.

I work on projects involving:

- 🖥️ **Windows desktop applications** — modernizing classic software while preserving familiar interfaces and functionality.
- 📚 **Digital documents and e-books** — editors, viewers, converters, and document processing tools.
- 🛠️ **Software maintenance** — compatibility improvements, bug fixes, dependency updates, and performance optimization.
- ⚙️ **Automation and development tools** — utilities that simplify everyday tasks.
- 🎮 **Game porting and preservation** — experimental projects exploring software portability across platforms.

I believe that useful software deserves to remain available, reliable, and relevant, even as technologies evolve.

### 🚀 Featured projects

**📖 [FictionBook Editor Next](https://github.com/sklart/fictionbook-editor-next)**

Modernization and continued development of the classic FictionBook Editor for Windows.

The project focuses on preserving the familiar FB2 editing experience while improving compatibility, stability, document processing, import/export capabilities, and the underlying technology.

**📚 [WinDjView Extended](https://github.com/sklart/WinDjView-Extended)**

Continued development of the lightweight DjVu document viewer for Windows.

The goal is to preserve its fast, native interface while modernizing dependencies, improving reliability, and maintaining compatibility with modern Windows environments.

**🎮 [Space Rangers HD — Nintendo Switch Port](https://github.com/sklart/space_rangers_hd_a_war_apart_port)**

An experimental, unofficial homebrew port of Space Rangers HD: A War Apart to Nintendo Switch.

The project focuses on adapting the game's technical components to a different platform. Work in progress — not a complete playable release.

Считаю, что хорошие программы заслуживают дальнейшего развития: они должны оставаться доступными, надёжными и актуальными даже спустя много лет после своего появления.

### 🚀 Основные проекты

**📖 [FictionBook Editor Next](https://github.com/sklart/fictionbook-editor-next)**

Модернизация и дальнейшее развитие классического редактора FictionBook Editor для Windows.

Цель проекта — сохранить привычные возможности редактирования FB2, улучшив совместимость, стабильность, обработку документов, импорт и экспорт, а также обновив внутренние компоненты программы.

**📚 [WinDjView Extended](https://github.com/sklart/WinDjView-Extended)**

Дальнейшее развитие компактной программы для просмотра документов DjVu в Windows.

Основное внимание уделяется сохранению быстрого нативного интерфейса, обновлению устаревших компонентов, повышению надёжности и совместимости с современными версиями Windows.

**🎮 [Space Rangers HD — порт для Nintendo Switch](https://github.com/sklart/space_rangers_hd_a_war_apart_port)**

Экспериментальный неофициальный homebrew-порт игры «Космические рейнджеры HD: Революция» для Nintendo Switch.

Проект посвящён адаптации технических компонентов игры для другой платформы. Разработка продолжается, полноценная игровая версия пока не готова.
